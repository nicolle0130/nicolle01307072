
🎬 나만의 영화 티어리스트 기획서
1. 누가 쓰나 (사용자)
		사용자 본인: 개인적으로 관람한 영화를 기록하고 주관적인 등급을 매겨 관리하고 싶은 1인 사용자.
2. 무엇을 하려고 (목적)
		영화 분류: 영화 제목을 직접 입력하여 추가하고, 드래그 앤 드롭으로 등급(Tier)을 분류함.
		데이터 보존: 브라우저를 새로고침하거나 재접속해도 내가 만든 리스트가 사라지지 않고 유지되게 함.
3. 화면과 동작 (UI/UX)
		화면 구성:
		상단: 영화 제목 입력창과 '추가' 버튼.
		중앙: 등급별 행(Row) 구성 (S, A, B, C, D 및 미분류 영역).
		디자인: 블루 계열의 포인트 컬러를 사용한 깔끔하고 미니멀한 스타일.
		주요 동작:
		입력: 사용자가 텍스트 박스에 제목을 타이핑하여 리스트에 추가.
		이동: 추가된 영화 아이템을 마우스로 드래그하여 원하는 티어 칸에 배치.
		저장: 아이템 추가 및 위치 이동 시 브라우저의 LocalStorage에 자동 저장.
4. 필요한 자료
		기술 스택: HTML, CSS, JavaScript (외부 라이브러리나 서버 없이 단일 파일로 구성).
		데이터: 사용자가 직접 입력할 영화 제목 텍스트.
5. 완성 기준
		드래그 앤 드롭 기능이 오류 없이 부드럽게 작동해야 함.
		페이지를 새로고침했을 때 기존에 배치한 영화들과 티어 위치가 그대로 유지되어야 함.
		블루 포인트가 적용된 깔끔한 UI 디자인이 구현되어야 함.

기획 단계에서 아래 항목들은 아직 명확히 정해지지 않았습니다. 필요에 따라 나중에 추가할 수 있습니다.
		수정 및 삭제 기능: 이미 추가한 영화의 제목을 수정하거나, 리스트에서 완전히 삭제하는 기능의 포함 여부. (현재 제공된 코드에는 편의상 삭제 버튼이 포함되어 있습니다.)
		이미지 저장 기능: 완성된 티어리스트를 이미지 파일(PNG/JPG)로 내려받는 기능의 필요 여부.
		모바일 지원: PC 마우스 드래그 외에 스마트폰 터치 드래그 기능 지원 여부.
		폰트: 특정 선호하는 글꼴(폰트) 지정 여부.
